# V7 — Section scrolling and themed 3D

Verified locally on 2026-10-06 at http://localhost:3017.

## Behavior

- Desktop at least 1060px wide and 700px high uses native mandatory scroll snap with section stops: opening, story, campaign, details, colorways, closing.
- Main sections fit tested desktop viewports (1440×700, 1920×1080, 2494×1321). The compact desktop rules reduce spacing and colorway heading size, retaining readable content.
- Shorter screens and tablets use proximity snapping. Mobile detail articles have individual stops. Oversized content remains scrollable; the footer has an end snap target so End can reach the final content.
- No JavaScript scroll hijacking or GSAP pinning. Reduced motion disables smooth scrolling.
- Inline and expanded 3D inherit the parent theme using CSS variables, including Sakura, Lagoon and Citrus. Canvas remains transparent.
- Inline wheel events bypass OrbitControls without preventing browser scrolling. Expanded viewers use wheel zoom and lock body scrolling; drag, touch pinch, zoom buttons, reset, sole view and Escape remain available.
- Existing V5 assets and V6 single-active-viewer/cache behavior are reused.

## Verification

- PASS `npm run lint`.
- PASS `npm run typecheck`.
- PASS `npm run build` — production static build.
- PASS `npm test` — **19/19**, 28.7 seconds.
- Tests cover forward/reverse real wheel scrolling, all desktop stops, content bounds, short/mobile reading, Home/End/PageDown, resizing, reduced motion, theme inheritance for seven cards and three colorways, modal accessibility, inline-vs-expanded wheel behavior, plus the V6 regressions.
- The new tests exposed oversized details/colorway sections at 700px height and End stopping above the footer. Responsive spacing/card sizing and a footer end snap target fixed these verified failures.
- Replaced the old mid-section scroll assertion because it conflicted with the approved snapping behavior; section navigation and absence of pinning remain asserted.

- Browser verification uses local Chromium. Safari and physical mobile hardware were not tested.
- Touch interaction is simulated through CDP. Native scroll feel can vary with browser and input device.
